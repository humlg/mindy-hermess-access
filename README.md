# Mindy Hermess access
Mindy Hermess access is a personal OAuth application used by me only to let my own personal assistant read and manage my own Google Calendar, Google Tasks and a dedicated assistant Gmail mailbox.
This application is not offered to the public and is not available for use by anyone other than its owner.
What the application accesses
Google Calendar: reads and creates events on David Huml's calendar.
Google Tasks: reads, creates, updates and completes tasks in David Huml's task lists.
Gmail (assistant mailbox only): reads, sends and organizes email in the dedicated assistant mailbox. It does not access my own primary Gmail account.
The application requests only the scopes listed above. It does not access Google Drive, Contacts or any other Google data.
How data is handled
OAuth tokens are stored only on the owner's private server, with restricted file permissions.
Data retrieved from Google is used only to carry out requests made by the owner. It is not shared with third parties, sold, or used for advertising.
Data is not stored beyond what is needed to complete those requests.
The application is not used to collect information about any other users.
## Revoking access
You can revoke this application's access at any time from your Google account at https://myaccount.google.com/permissions.
